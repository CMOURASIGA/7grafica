# SPEC 05 - Pedidos, Trabalhos e Kanban

## Objetivo
Controlar a execucao operacional de ponta a ponta.

## Regra principal
Um Pedido pode gerar varios Trabalhos.

## Trabalho
Campos minimos:
- codigo
- pedido
- cliente
- tipo
- workflow
- status
- prioridade
- prazo
- responsavel
- origem
- observacao

## Kanban
- colunas derivadas do workflow
- drag and drop com regras
- bloqueio de transicao invalida
- cores por prazo
- filtros
- busca
- responsavel
- prioridade
- cliente
- categoria

## Etapas
- humana
- automatica
- hibrida

## Timeline
Registrar:
- criacao
- mudanca de status
- responsavel
- aprovacao
- arquivo
- producao
- consumo
- pagamento
- entrega
- retrabalho
- cancelamento
