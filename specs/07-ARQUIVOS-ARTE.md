# SPEC 07 - Arquivos e Arte

## Objetivo
Controlar documentos, artes e aprovacoes.

## Analise basica
No MVP:
- tipo
- numero de paginas
- dimensao
- orientacao
- tamanho do arquivo
- metadados relevantes para impressao

## Evolucao
Preflight avancado:
- RGB/CMYK
- sangria
- fontes
- resolucao
- cobertura de tinta
- PDF/X

## Criacao de arte
Quando o servico exigir arte:
Briefing -> Criacao -> Aprovacao -> Ajustes -> Aprovacao final -> Producao

## Versoes
- V1, V2...
- data
- autor
- comentario
- status
- registro de aprovacao
