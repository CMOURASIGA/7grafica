# SPEC 11 - Entrega e Historico

## Entrega
Modalidades:
- retirada
- entrega propria
- motoboy
- transportadora
- outro

## Status
- pronto
- aguardando retirada
- saiu para entrega
- entregue
- falha na entrega

## Historico
Toda acao relevante deve compor timeline do pedido.

Exemplos:
- solicitacao recebida
- cliente identificado
- orcamento criado
- orcamento enviado
- aprovado/rejeitado
- pedido criado
- trabalho criado
- etapa iniciada/concluida
- arquivo aprovado
- material consumido
- pagamento registrado
- pronto
- entregue
