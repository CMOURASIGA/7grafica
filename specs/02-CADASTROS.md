# SPEC 02 - Cadastros Mestres

## Objetivo
Criar os cadastros que sustentam todos os processos.

## Cadastros
- clientes
- contatos
- e-mails alternativos
- fornecedores
- servicos
- categorias de servico
- materiais
- unidades de compra
- unidades de consumo
- conversoes
- equipamentos
- capacidades de equipamento
- formas de pagamento
- workflows
- etapas
- usuarios
- papeis e permissoes

## Regras
- Cliente pode existir sem login.
- Cliente pode ser PF ou PJ.
- Um cliente pode possuir varios contatos.
- Um contato pode possuir varios e-mails.
- E-mail deve ser indexado para identificacao rapida.
- Permitir Consumidor nao identificado no PDV.
