# SPEC 01 - Foundation

## Objetivo
Criar a base tecnica e visual do 7Grafica.

## Escopo
- Next.js App Router
- TypeScript
- Supabase/Postgres
- RLS por empresa
- autenticacao
- RBAC
- auditoria
- shell autenticado
- componentes visuais alinhados ao 7Commander
- whitelabel
- responsividade
- base PWA se aplicavel

## Requisitos de seguranca
- isolamento por empresa
- nenhum dado cross-tenant
- logs de acoes relevantes
- preparacao para 2FA
- tokens de acompanhamento nao sequenciais

## Criterio de aceite
A aplicacao deve possuir shell, login, navegacao, perfis e padrao visual validados antes de iniciar dominio funcional.
